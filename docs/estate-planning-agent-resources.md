# Estate Planning Agent: Authoritative Information Sources

## Overview

This document catalogs the best authoritative sources of information for building an AI-powered estate planning agent capable of performing at the level of a licensed estate planning attorney with expertise across all 50 U.S. states. Sources are ranked by authority and organized by category.

Estate planning encompasses wills, trusts, powers of attorney, healthcare directives, beneficiary designations, probate, guardianship, asset titling, and federal/state tax planning. True attorney-level expertise requires mastery of both federal law (uniform across states) and each state's unique statutes, regulations, and case law.

## 2. Uniform Laws — High Authority (Adopted in Many States)

Uniform laws drafted by the Uniform Law Commission (ULC) form the backbone of estate planning law in most states.

| Uniform Act | States Enacted | Key Topics | Source |
|-------------|----------------|------------|--------|
| Uniform Probate Code (UPC) | ~18 states (AL, AK, AZ, CO, FL, HI, ID, ME, MI, MN, MT, NE, NM, ND, SC, SD, UT, WI, WY + others with partial adoption) | Intestacy, wills, probate, trusts | https://www.uniformlaws.org/committees/community-home?CommunityKey=a539920d-c477-44b8-84fe-b0d7b1a4cca8 |
| Uniform Trust Code (UTC) | ~35 states | Trust formation, modification, termination, trustee duties | https://www.uniformlaws.org/committees/community-home?CommunityKey=193ff839-7955-4846-8f3c-ce74ac23938d |
| Uniform Power of Attorney Act (UPOAA) | ~26 states | Durable POA, agent duties | https://www.uniformlaws.org/committees/community-home?CommunityKey=2e1b2b4d-2a01-4a14-8b7f-3a8f28f12d3e |
| Uniform Healthcare Decisions Act (UHCDA) | ~10 states | Healthcare proxy, living will | https://www.uniformlaws.org |
| Uniform Adult Guardianship and Protective Proceedings Jurisdiction Act (UAGPPA) | ~49 states | Guardianship jurisdiction | https://www.uniformlaws.org |
| Uniform Disposition of Community Property Rights Act (UDCPRA) | ~16 states | Community property at death in common-law states | https://www.uniformlaws.org |
| Uniform Fiduciary Income and Principal Act (UFIPA 2018) | ~26 states | Trust accounting, income/principal | https://www.uniformlaws.org |
| Uniform Real Property Transfer on Death Act (URPTODA) | ~19 states | Transfer-on-death deeds | https://www.uniformlaws.org |

**Primary Source:** https://www.uniformlaws.org — Full text of all uniform acts, enactment maps, and legislative history.

## 13. Recommended Architecture for an Estate Planning AI Agent

### 13.1 Knowledge Base Construction

A licensed-attorney-level estate planning agent requires a **multi-layer knowledge base**:

```
Layer 1 — Federal Statutes & Regulations (uniform across all states)
  - Full IRC Subtitle B (estate, gift, GST taxes)
  - Treasury Regulations (26 CFR Parts 20, 25, 26)
  - IRS Revenue Rulings, Notices, Procedures
  - Federal case law (Tax Court, Federal Circuit, SCOTUS)

Layer 2 — Uniform Law Foundation
  - Full text of UPC, UTC, UPOAA, UHCDA, UAGPPA, UFIPA, URPTODA, UFADAA
  - ULC enactment maps showing which version each state adopted
  - Non-uniform amendments by state

Layer 3 — State-Specific Law (×50)
  - Each state's probate code, trust code, will statute
  - State estate/inheritance/gift tax statutes and regulations
  - State case law (Supreme Court + appellate)
  - State administrative guidance and forms

Layer 4 — Secondary Sources & Treatises
  - Bogert, Scott on Trusts, Casner & Pennell, Bove & Langa
  - ACTEC Commentaries and state survey charts
  - Law review articles (RPTELJ, Tax Lawyer)

Layer 5 — Practical Knowledge
  - CLE materials (Heckerling proceedings, ALI-CLE)
  - ABA RPTE Probate & Property articles
  - Sample forms and drafting guides
  - State bar ethics opinions on estate planning
```

### 13.2 Key Data Gaps and Challenges

1. **Currency**: Estate planning law changes frequently (tax reform, new state enactments). The agent must have a pipeline for continuous updates.
2. **State non-uniformity**: Even states that adopted the UTC or UPC often enacted non-uniform amendments. The agent must track these amendments per state.
3. **Community property vs. common law**: 9 states (AZ, CA, ID, LA, NV, NM, TX, WA, WI) are community property states; this fundamentally changes planning for married couples.
4. **Portability and elections**: Federal portability of the deceased spousal unused exclusion (DSUE) requires understanding of current exemption amounts (adjusted annually for inflation).
5. **Sunset provisions**: The TCJA 2017 provisions (doubling the exemption) are scheduled to sunset after 2025 unless Congress acts, materially changing planning strategies.
6. **Case law interpretation**: Courts regularly issue opinions that change how statutes are interpreted; training data must include recent decisions.

### 13.3 Recommended Authoritative Source Priority

For maximum attorney-level reliability, prioritize sources in this order:

1. **Primary — Highest Authority**: IRC + Treasury Regulations, state statutes in force
2. **Primary — High Authority**: Federal and state court opinions (Tax Court, state supreme courts)
3. **Secondary — High Authority**: ACTEC state surveys, uniform act comments, IRS published guidance
4. **Secondary — Persuasive**: Bogert/Scott treatises, Heckerling proceedings, ABA RPTE articles
5. **Secondary — Supplementary**: Bar newsletters, CLE materials, practitioner blogs

### 13.4 Recommended Data Pipeline

```
1. Ingest primary statutes via official state code repositories (Justia/Cornell LII for free;
   Westlaw/Lexis API for commercial-grade currency and coverage)

2. Ingest IRC and CFR via eCFR API + Congress.gov API (free, authoritative, machine-readable)

3. Ingest federal case law via Harvard Caselaw Access Project + CourtListener API

4. Ingest state case law via Westlaw/LexisNexis API or Fastcase

5. Structure knowledge by jurisdiction + topic using a taxonomy aligned to:
   - ABA RPTE topic classification
   - ACTEC state survey categories
   - State-by-state tax profile (estate tax Y/N, inheritance tax Y/N, community property Y/N)

6. Implement retrieval-augmented generation (RAG) with jurisdiction-aware routing:
   - Detect client state of domicile and asset locations
   - Filter retrieved context to relevant federal law + that state's law
   - Supplement with uniform law foundation

7. Implement a change-detection pipeline:
   - Monitor state legislative sessions for bill passage
   - Monitor IRS Internal Revenue Bulletins weekly
   - Monitor Tax Court and state supreme court decisions
   - Re-index changed content within 24-48 hours of enactment/publication
```

## 15. Ethical and Regulatory Considerations for the Agent

An estate planning AI agent must be designed with the following constraints:

- **Unauthorized Practice of Law (UPL)**: The agent must not hold itself out as providing legal advice. It should explicitly recommend consultation with a licensed attorney for legal decisions.
- **State bar rules vary**: Some states (e.g., California, Texas) have strict UPL enforcement; the agent's output framing must comply with each state's rules.
- **Confidentiality**: Estate planning involves highly sensitive client information (asset values, beneficiary choices, family dynamics). Any data pipeline must comply with applicable privacy laws and attorney-client privilege considerations if used by licensed attorneys.
- **Currency disclaimer**: The agent must always indicate the date of its knowledge base and caution that law changes frequently.
- **Tax advice disclaimer**: Federal Circular 230 governs tax advice by attorneys and CPAs; the agent's outputs touching on tax must be appropriately disclaimed.
